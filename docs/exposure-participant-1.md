# Guía de exposición — Participante 1: Frontend y experiencia de usuario

Objetivo: abrir la demo mostrando cómo se usa la aplicación desde el dashboard, sin explicar código ni detalles internos.

## Resumen 

“Mi parte es mostrar la aplicación desde el punto de vista del usuario. Voy a explicar qué se ve en pantalla, cómo se ejecuta el flujo, cómo se revisa el resultado final y cómo se consulta el historial.”

## Qué problema explica

La app automatiza la creación de un post basado en tendencias. El frontend permite usar ese proceso de forma visual: elegir pasos, correr el pipeline, ver el avance, revisar el post final y consultar corridas anteriores.

## Guia demo

- El dashboard principal.
- Las cards del flujo: Descubrir, Filtrar, Elegir, Crear, Publicar y Medir.
- El botón **Ejecutar todo**.
- El botón **Correr selección**.
- Las animaciones mientras el pipeline corre.
- El resultado final del post.
- La página **Historial**.
- La opción de reutilizar un tema.

## Resumen

“Esta es la pantalla principal de la aplicación. Desde acá una persona puede ejecutar el flujo completo para generar un post de tendencia.

Cada card representa una etapa del proceso: primero se descubren tendencias, después se filtran, se elige un tema, se crea el contenido, se publica en modo simulado y finalmente se mide si todo quedó bien.

El botón Ejecutar todo selecciona todas las etapas. Después, con Correr selección, empieza el proceso real. Mientras corre, la interfaz muestra movimiento en las cards para indicar que el flujo está trabajando.

Cuando termina, podemos ver el resultado final: el tema elegido, la imagen, el texto del post, los hashtags y el estado de publicación.

También tenemos una página de Historial. Ahí se pueden ver corridas anteriores, filtrar por fecha o tema y reutilizar un tema para generar un nuevo post sin empezar desde cero.”

## Cierre

“El frontend permite que todo el pipeline sea fácil de usar y entender, incluso para alguien que no sabe programación.”
